# Honor Duo One 1.0.0

荣耀 MagicOS 的三合一状态栏模块。液态玻璃设置界面与三合一渲染架构来自 [HonorDuo](https://github.com/odomu/HonorDuo)，玻璃样式参考 [HonorHook](https://github.com/coderstory/HonorHook)，圆环与双排信号的实现思路参考 [HonorDuoBar](https://github.com/nisu123f/HonorDuoBar)。本仓库在其基础上做整合、修 bug 与打磨。

包名 `io.github.honorduoone`，与上述三个模块可以共存，但**功能重叠，不建议同时启用**。

## 三合一字形

- **圆环 / 胶囊 / 矩形**三种排布，切换即时自适应；胶囊展开时对状态栏图标做碰撞避让
- **分区摆件**：胶囊分上部、中部、下部三个槽位，中部最多放 3 件，排布按三等分居中；圆环按内圈点位放置
- **可放部件**：信号点、Wi-Fi、网络制式、电量数值、充电闪电、温度、功率、帧率、时钟、流量箭头
- **防烧屏**：开启后字形沿 3×3 离散网格每 30 秒位移 1dp，边界内钳制

## 双排信号

- 双卡信号上下两排，制式另起一行；与三合一互斥，开启后字形整体让位
- 可选在柱状图右侧画流量箭头，独立开关

## 流量箭头组件

- 单组件内左半移动数据、右半 Wi-Fi，未连接的一侧画暗灰占位而不是消失
- 移动侧以 `getDataActivity` 驱动，Wi-Fi 侧以 `TrafficStats` 差分驱动；熄屏停采样

## 移动信号与网络制式

- 4 柱 / 5 柱信号柱两种风格，5 柱等比缩放到与 4 柱同宽
- 5G 判定以电话读数为主、图标名为辅；NSA 场景回落显示 4G，避免“关掉 5G 仍显示 5G”
- 双卡制式上下两行分别显示，可选择只显示当前数据卡

## 时钟与硬件读数

- 秒、日期、星期、农历、天气五项都可单独开关，**默认全关**；五项全关时完全不接管原生时钟
- 电池百分比、充电闪电（插电后显示 5 秒）、温度告警、充电功率、帧率

## 息屏显示

- 全屏 AOD 复用状态栏行，因此熄屏时模块会把行内电池交还宿主，亮屏再收回 —— 修复此前“偶尔息屏没有电池图标”的时序竞争

## 其他

- **模块总开关**：关闭后所有修改立即失效，状态栏完全回到系统原生
- 状态栏图标替换、通知净化、控制中心音量条长按切换媒体输出、蓝牙耳机电量（弧线 / 数字两种）
- 熄屏期间停掉全部轮询、动画与采样，避免 SystemUI 后台功耗异常

## 安装

1. LSPosed 中启用本模块，作用域勾选**系统界面**
2. 重启 SystemUI（或在模块设置页「关于」里一键重启）
3. 打开模块设置页调整排布
