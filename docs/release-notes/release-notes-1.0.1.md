## Honor Duo One 更新日志（含内测期全部记录）

合并自 HonorDuo、HonorHook、HonorDuoBar 三上游的三合一状态栏模块，从首个公开发布 v1.0.0（141）到本次 v1.0.1（142）的完整变更记录；内测期（v1.1.0–v1.3.15，versionCode ≤ 140）未单独发版，一并汇入本日志。

### 新增功能

- **三排布风格**：圆环 / 胶囊 / 圆角矩形三种排布，保留 HonorDuo 完整液态玻璃 DIY 设置界面；三种风格拆分为独立子设置页，可分别修改显示内容。
- **左右两侧组件**：圆环与胶囊新增「左侧 / 右侧」位置，标签按物理顺序排列。圆环两侧可放任意组件——信号点为 9 点 / 3 点居中的珠排（跨度随柱数自适应），Wi-Fi 为环外两段同心弧，其余组件落在为其切出的开口里按弦宽拟合；胶囊两侧收信号排与 Wi-Fi。旧布局自动兼容，升级不丢排布。
- **双排信号**：采用 Duo 外置信号画法（drawOutSignal），带实时上传 / 下载箭头与开关，活动箭头跟随「显示流量活动图标」；双卡堆叠信号（双排柱样式）默认开启，含堆叠开关、堆叠风格与流量活动图标选项。
- **模块生效范围**：控制中心 / 通知面板 / 锁屏界面多选，取消勾选的位置整行交还原生图标；三项全排除自动归一为「所有位置」。
- **蓝牙电量**：正方环样式、环内显示电量数字；弧线 / 数字两种样式可选；支持仅放置组件（不开开关）取数，重启后无需等电量广播即可出数。
- **天气日期组件**：带独立开关。
- **备份与恢复**：设置可导出导入。
- **WiFi / 流量上下行三角标识**：显示开关由用户选择。
- **HonorHook 状态栏 / 通知栏图标替换**全量并入；控制中心音量条长按弹出媒体输出弹窗。
- **关于页**：更新入口与 GitHub 地址。

### 修复

- 元数据携带 UTF-8 BOM 导致 LSPosed 无法识别系统界面推荐作用域。
- 模块向系统界面发送全局重载广播，与其他 HonorDuo 系列模块串扰，未激活本模块时状态栏仍被修改——已移除全部跨模块广播。
- 全屏息屏下电池图标被误隐藏，息屏无法查看剩余电量。
- 5G 关闭时 4G 显示异常。
- 下拉状态栏卡顿：电话读数移出布局路径。
- 蓝牙电量粘滞残留；蓝牙图标隐藏逻辑优化。
- 双排信号与「移动信号」卡片开关冲突：柱数 / 箭头 / 堆叠开关接线对齐；三合一专属设置项在双排模式下灰掉并加提示。
- 拔卡后信号组件残留、无卡时意外消失：增加卡槽读数有效性校验。
- 充电闪电 5 秒不消失、无状态更新时常驻：主动预约到点重绘保证准时消失。
- 充电呼吸样式未纳入总控：呼吸动画与闪电 5 秒消失逻辑同步。
- 时钟全关闭内容项后仍被修改：仅以内容开关作为触发依据。
- WiFi 组件位置偏移；组件对齐错误导致右侧组件超出胶囊。
- 胶囊中部扩展为最多 3 个组件三等分居中布局，轮廓右缘同步加宽。

### 其他

- 发布资产签名与历史版本同证书，可覆盖安装；提供无广告版与带赞赏码版两个构建变体。
- 设置修改后需重启 SystemUI 生效；安装后请在 LSPosed 中勾选系统界面作用域。
