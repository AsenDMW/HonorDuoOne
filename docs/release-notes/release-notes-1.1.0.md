# Honor Duo One 1.1.0（150）

本次为正式发布版，同步上游 Duo 1.0.6，并修复若干状态栏稳定性问题。

## 新增

- **隐藏隐私指示**：可关闭状态栏右侧的绿色圆点（相机/麦克风使用中）。默认关闭；开启后无法再从状态栏判断是否有应用在录音或录像。

## 修复

- **蓝牙卡顿**：放置蓝牙电量组件并连接较久后，下拉状态栏会卡顿。此前每 1% 电量变化都会递归遍历整棵状态栏视图树并改写可见性；现仅在「未知 ↔ 已知」融合态翻转时执行，普通电量变化只重绘字形。
- **横屏下拉时钟异常**：横屏下拉瞬间状态栏高度尚未测出（高度为 0），字号被压成 0、时钟缩成一点。现在高度未知时不缩放。
- **状态栏时钟消失**：宿主重新布局状态栏行时会替换掉时钟 View，而我们收不到这次替换。现在每次布局都会检查，缺失即自动补回，无需再等设置变更。
- **面板展开/收起蓝牙图标同步**：展开面板时还原原生蓝牙图标，收起时重新融合进字形。
- **恢复备份不完整**：导入备份后，时钟上下行偏移、行距、农历开关、日期/星期格式、星期/日期/农历颜色、模块生效范围等键未被推送，导致重启后仍不生效。现已补推（按本模块设计，仍需重启 SystemUI 后生效）。

## 优化

- `hookVisibility` 仅在可见性相关的 `setFlags` 写入时执行抑制遍历，减少无谓开销。

## 兼容

- 与 v1.0.0 使用同一签名证书，可直接覆盖安装；versionCode 150。
