# Honor Duo One 1.1.10（167）

本次为正式发布版，改动覆盖自 1.1.8 以来所有用户可感知的内容。

## 功能添加

- **鸿蒙堆叠信号**：功能开关 → 鸿蒙堆叠信号，开启后信号图标改由本模块内置的鸿蒙堆叠资源绘制，双卡堆叠、按信号强度选图与原生一致；开启时本模块自带的其它绘制会整体停用，因此会先说明影响、确认后才生效。各开关的开启状态会保留，关闭本项即按原状态恢复。资源与判定逻辑来自 [StackedSignal_5G 原帖](https://www.coolapk.com/feed/74608300?s=NTAxYmJmN2QyZDUxYzFnNmFlZGRjYmJ6a1662)。
- **关闭全部**：功能开关 → 关闭全部，一次关闭「已开启」的全部功能（包含模块总开关），一键回到原生状态；执行前会先确认。
- **关于页「已开启显示项」**：关于 → 已开启显示项，列出当前所有开启的功能项，可就地单独关闭，也可一次全部关闭；标题右侧有箭头提示该行可点。

## 功能修复

- **下拉通知栏掉帧（开启通知中心天气后）**：开启「显示天气」后，下拉通知中心与控制中心横滑时会明显卡顿。原因是天气数据每次更新都触发一次完整读取，读取本身又会再通知一次，形成连续读取，并在展开动画期间重排状态栏、重算日期行。现在同一串变化只读取一次，并限制两次读取的最小间隔，状态栏重排只在开启「时钟天气」时进行，日期行重算延后到展开动画结束并复用上次结果。
- **点击日期行打开的是日历而不是天气**：开启「点击跳转天气」后，点击通知中心日期行仍然跳到日历。现已按系统天气应用的启动入口显式打开，并自动收起通知栏；系统里没有天气应用时不做跳转。

## 功能变更

- **点击跳转天气的代价说明**：开启「点击跳转天气」后，通知中心日期行的整行点击都用于打开天气应用，系统原本「点日期打开日历」的行为不再可用。拨开该项时会先弹出提示确认，取消则保持关闭；关闭该项即恢复原生日历跳转。

**安装**：覆盖安装即可，设置全部保留。
