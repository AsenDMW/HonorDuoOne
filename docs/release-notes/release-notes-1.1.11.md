# Honor Duo One 1.1.11（169）

## 功能添加

- **诊断页**：设置 →「关于」→「诊断信息」，一页看清设备与系统版本、模块是否正常加载、作用域是否勾选系统界面、各功能是否挂载成功；失败时直接写明是「找不到目标类」还是「方法对不上」，并给出类名、方法名与参数个数。同时探测鸿蒙堆叠信号的目标类、主题包与内置图标，列出最近的模块日志，整份内容可一键复制或导出为文本文件。只在打开这一页时读取，不影响日常使用。
- **关于页致谢**：设置 →「关于」最底部新增「致谢」，列出 HonorHook、HonorDuoBar、HonorDuo 三个参考项目与鸿蒙堆叠信号的原帖出处，每行可点击直接打开对应地址。
- **鸿蒙堆叠信号出处标注**：设置 →「排布」→「功能开关」→「鸿蒙堆叠信号」，开关说明下方新增一行出处文字，点一下即可查看该资源的原帖；关于页「致谢」里也补上了同一条目。

---

**安装**：覆盖安装即可，设置全部保留。已装 1.1.11-test 的设备可直接覆盖，无需卸载。
