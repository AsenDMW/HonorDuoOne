# Honor Duo One 1.1.12（170）

## 功能添加

- **双卡停用显示**：在系统设置里停用一张卡后，状态栏对应那一排改用未点亮点的轨道色，位置与行高不变，停用卡不显示网络制式，另一张卡照常显示信号与制式。卡 1 停用、卡 2 停用、只开一张、两张先后开启这几种顺序，停用的那排都会保持灰，不会被另一张卡的信号带亮。
- **关闭功能项后可撤销**：排布 →「功能开关」→「关闭全部」，以及关于 →「已开启显示项」里的关闭操作，完成后 5 秒内可在提示条上点「撤销」，按关闭前的整份设置还原，互斥开关与布局一并恢复，不必逐项重新开启。

## 功能变更

- **已开启显示项的单行操作**：关于 →「已开启显示项」，改为只有右侧开关能关闭，点标题或行的空白处不再触发关闭；拨动开关先弹出确认框，确认后才生效。
- **停用状态有约 2–4 秒确认时间**：卡是否停用要经过连续两次状态确认，切卡后显示会在两次采样内完成切换；确认前不会把正常卡误判为停用。

---

**安装**：覆盖安装即可，设置全部保留。
