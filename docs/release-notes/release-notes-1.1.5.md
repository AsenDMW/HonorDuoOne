# Honor Duo One 1.1.5（158）

本次为正式发布版，重点修复下拉状态栏卡顿，并同步上游 Duo 1.0.7 的稳定性改进。1.1.1～1.1.4 为内测版本，其修复一并包含在本次发布中。

## 修复

- **下拉状态栏卡顿（放置蓝牙电量组件时）**：下拉及控制中心/通知中心横滑过程中，系统逐帧播放图标反色动画；蓝牙电量正方环此前每帧都重新摊平圆角矩形、用 PathMeasure 截取进度段并测量文字，超出帧预算（断开蓝牙即流畅的根因）。现进度段 Path、字号、基线按（尺寸/电量/画法/字重/字体）预烘焙缓存，逐帧只换颜色重放，颜色与位置变化不再触发几何重算。
- **下拉反色逐帧全量重排**（1.1.3 内测）：反色动画逐帧触发时，此前对状态栏整行执行全量刷新；现改为轻量重绘路径。
- **蓝牙电量跳格刷新**（1.1.2 内测）：电量每跳 1% 曾触发整组字形重绘，现已按帧去重。

## 优化

- 同步上游 Duo 1.0.7：农历改为查表常量、FontMetrics 复用；状态栏时钟恢复加固（宿主 detached 检测、横屏亮屏补放、重试防死循环）。
- 蓝牙电量组件的显示内容（弧线 / 数字）支持多选叠加。

## 兼容

- 与 v1.0.0 使用同一签名证书，可直接覆盖安装；versionCode 158。
