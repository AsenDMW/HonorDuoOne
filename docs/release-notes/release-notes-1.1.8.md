# Honor Duo One 1.1.8（161）

本次为正式发布版，1.1.6、1.1.7 为内测版本，其改动一并包含在本次发布中。

## 功能添加

- **通知中心显示天气**：通知中心 → 显示天气，开启后在日期行末尾追加实时天气与气温，原日期显示不受影响；天气样式可选纯文字、图标或图标加文字。
- **点击跳转天气**：通知中心 → 点击跳转天气，开启后点击通知中心日期行直接打开系统天气应用并自动收起通知栏；关闭后日期行恢复原生行为。需先开启「显示天气」。

## 功能修复

- **下拉状态栏卡顿（连接蓝牙耳机时）**：放置蓝牙电量组件后，下拉状态栏及控制中心与通知中心横滑会掉帧，断开蓝牙即恢复流畅。现电量进度、字号与文字位置改为按当前尺寸与电量预先算好并复用，反色动画逐帧只换颜色，不再重复计算。
- **通知中心天气不显示**：部分 MagicOS 版本的系统天气只通过专用接口提供数据，此前读取方式取不到内容。现优先走该接口，取不到再回退原有读取方式。
- **天气变化后不刷新**：天气数据更新后，通知中心要等到下一整分钟才显示新内容。现在数据一更新就立即刷新日期行。
- **大字号字形被裁切**：把字形尺寸调大（如 24dp）后，字形反而被状态栏图标行压小或被边缘切掉。现字形始终按设定尺寸绘制，并放宽沿途容器的裁剪限制。
- **防烧屏位移被裁切**：开启防烧屏后，字形按网格微移时边缘会被切掉一部分。现改为在画布内平移，不再移动视图本身。
- **LSPosed 作用域没有推荐应用**：模块启用页此前不显示任何推荐应用。现在会推荐并预置「系统界面」作用域。
